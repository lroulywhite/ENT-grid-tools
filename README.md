# ENT | Explore Grid Tools and the Reading Pane [Interaction]

Open-exploration Interaction for the Momentus Enterprise Learning Center. The learner chooses a tool and explores it on the real Events list: Grid Tools (search, Tools, Add, the gear icon, and Actions) and the Reading Pane.

- Product: Momentus Enterprise
- Format: self-contained HTML (`index.html`), embedded in Genially
- Built from approved captures of the Events list (All Events view), shown at the width they were captured (1272 px) and enlarged to fill the stage

## What learners do

- Find search, Tools, Add, and Actions in the grid header
- Open the gear icon menu to see its options
- Turn on the Reading Pane to see a selected record

## Embed in Genially

Use the HTML or embed widget with this snippet. The frame matches the 1920 x 1176 stage so the bar is not letterboxed.

```html
<iframe src="https://lroulywhite.github.io/ENT-grid-tools-reading-pane/" title="ENT Explore Grid Tools and the Reading Pane Interaction"
  width="1920" height="1176" style="border:0;width:100%;height:100%;" allowfullscreen loading="lazy"></iframe>
```

Recommend full-screen mode. Check the published Genially page for empty side bars and resize the frame if needed.

## Publish on GitHub Pages

1. Create a repo named `ENT-grid-tools-reading-pane` and push these files to `main`.
2. In the repo, open Settings > Pages, set the source to the `main` branch, root folder, and save.
3. Wait a minute, then open `https://lroulywhite.github.io/ENT-grid-tools-reading-pane/`. If the page looks stale, it is usually Pages caching.

```
git init
git add .
git commit -m "Add ENT Grid Tools and Reading Pane interaction"
git branch -M main
git remote add origin https://github.com/lroulywhite/ENT-grid-tools-reading-pane.git
git push -u origin main
```

## Before sharing widely

- Product or Security must confirm the demo data is mock. A Pages site is reachable by URL even when the repo is private (on most plans).
- Names in the capture were replaced with fictional ones. Someone should check they do not match real customers.
- Dates are as captured (2025).

## Notes for maintainers

- Behavior that was inferred, not captured: the Reading Pane switch toggling the pane on and off; the Actions menu and Tools menu shown with the pane off (their captures had the pane on); and the gear menu shown with a row selected (its capture had nothing selected).
- Not covered because not captured: the Add Event options and typed search.
- Raw captures are not in this repo. Do not commit them.
